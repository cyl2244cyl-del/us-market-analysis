## 날짜와 사건을 묶는 기준

미국 동부시간을 기준으로 **전 거래일 16:00 이후부터 해당 거래일 16:00까지**의 보도를 해당 거래일에 묶습니다. 따라서 11월 11일 장 마감 후 보도는 11월 12일 일지에 포함됩니다. 11월 12일 장 마감 후 새 보도는 다음 거래일로 넘깁니다. 장 마감 직후 발표된 최종 종가 통계는 해당 정규장의 수치로 사용합니다.

같은 거래일에 같은 연계 사건이 이어지면 `case_id`가 같은 하나의 블록에 출처와 문단을 덧붙입니다. 후속 거래일에도 같은 `case_id`를 유지합니다. 생성기는 해당 거래일까지의 기록을 읽어 ‘연계 보도 순서’에 누적합니다. 과거 일지에는 이후에 나온 보도가 섞이지 않습니다. 시각을 확인하지 못한 공식 문서는 시각을 추정하지 않고 날짜와 해당 거래일에 포함한 근거를 저장합니다.

출처별 문단은 공개된 내용을 요약하며, 단순한 등락을 특정 뉴스의 인과 효과로 단정하지 않습니다. ‘연계’는 고객·공급사·동종업계 관계를 뜻합니다. 예를 들어 CRWV는 네비우스 사건의 직접 당사자가 아닌 동종업계 기업입니다.

## 수치와 계산

- 가격·거래량: Stock Analysis 역사 표의 **2026-11-12 정규장 종가**와 과거 이력. 제공자는 S&P Global Market Intelligence이며 주식분할 조정을 명시합니다. 화면 상단의 실시간 가격은 사용하지 않습니다.
- 지수: AP의 11월 12일 최종 마감 통계. 등락률은 최종 종가와 포인트 변화로 계산합니다.
- 일간 등락률: `(당일 종가 / 전 거래일 종가 − 1) × 100`.
- QQQ 대비: 종목 등락률에서 QQQ 등락률을 뺀 **%p**입니다. 업종 ETF 대비로 표시하지 않습니다.
- 20일선: 당일 포함 최근 20거래일 종가의 단순평균. 이격률은 `(종가 / 20일선 − 1) × 100`.
- RSI 14: Wilder 방식. 확보한 49거래일 중 첫 14개 종가 변화의 평균 상승·하락으로 초기화한 뒤 순차 갱신합니다. 첫 이력일은 2026-09-04입니다. 더 긴 초기 이력을 쓰는 서비스와 값이 다를 수 있습니다.
- 거래량 배수: 당일 거래량을 **직전 20거래일 평균 거래량**으로 나눕니다. 분모에서 당일을 제외합니다.
- 확보한 이력이 49거래일이므로 60일선은 포함하지 않습니다. 계산과 화면에 11월 13일 가격은 사용하지 않습니다.
- 히트맵은 15종목 동일 면적이고 등락률 색 농도 상한은 ±7%입니다. 표시 숫자는 실제 등락률입니다.
