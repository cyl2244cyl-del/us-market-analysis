## 저장 원칙

로컬과 비공개 GitHub 저장소 `cyl2244cyl-del/us-market-analysis`의 역할을 분리합니다.

- 로컬: 예약 자동화, SQLite 데이터베이스, 생성기와 검증 작업을 계속 실행하는 운영 공간
- GitHub: 검증된 코드·설정과 사람이 읽을 Markdown 리포트를 정돈해 누적하는 프로젝트 공간
- SQLite, 백업, 차트 중간 파일: 로컬에만 유지
- 생성 결과는 검증에 성공한 경우에만 GitHub에 반영

현재 동작 중인 로컬 자동화와 파일 경로는 안정성을 위해 유지합니다. GitHub에는 로컬 폴더를 그대로 복제하지 않고, 장기 보관할 가치가 있는 코드·설정·리포트만 프로젝트 구조로 정리합니다.

자세한 운영 방식은 [운영 구조](docs/OPERATIONS.md)를 참고하세요.

## 자동화

| 자동화 | 실행 시각(KST) | 영구 결과 |
| --- | --- | --- |
| 일일 시장 리포트 | 화~토 09:00 | 날짜별 Markdown 및 완성 리포트 |
| 실적 시즌 문서 | 화~토 07:30 | 시즌 인덱스와 해당 종목 실적 문서 |

9개 종목 모두 회사별 질문이 들어간 상세 문서를 미리 만들고, `발표 전 대기 → 프리뷰 → 발표 결과 → 콜 분석 → 다음 정규장 반응 → 5거래일 회고` 순으로 같은 문서를 갱신합니다.

## 프로젝트 구성

- `config/`: 종목별 실적 핵심 질문과 자동화 설정
- `src/`: 원격 문서 생성기
- `reports/`: GitHub에서 바로 읽는 Markdown 리포트
- `docs/`: 운영 원칙과 복구 절차
- `일일리포트/`, `실적리포트/`: 기존 자동화 호환 경로(전환 기간 동안 유지)
