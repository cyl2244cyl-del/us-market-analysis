# 미장분석 리포트 보관소

9개 관심 종목(NVDA, AAPL, GOOGL, MSFT, AMZN, AVGO, META, SPCX, MU)의 자동 생성 리포트를 비공개로 누적 보관합니다.

## 자동화되는 파일

- `일일리포트/YYYY-MM-DD.md`: 날짜별 주가·등락률·밸류에이션과 주요 변동 원인
- `일일리포트/reports/YYYY/MM/YYYY-MM-DD.html`: 차트가 포함된 날짜별 완성 리포트
- `일일리포트/나스닥_통합_리포트.html`: 날짜별 리포트 목록
- `실적리포트/earnings_calendar.json`: 실적 일정과 발표 결과 데이터
- `실적리포트/index.html`: 실적 리포트 목록
- `실적리포트/tickers/*.html`: 종목별 실적 상세 리포트

## 보관 원칙

- 이 저장소에는 검증을 통과한 리포트 결과와 리포트 상태 데이터만 저장합니다.
- 실행 코드, SQLite 데이터베이스, 백업 파일, 이미지 중간 산출물, 인증정보는 로컬에만 유지합니다.
- 저장소는 비공개 상태를 유지하며 GitHub Pages를 사용하지 않습니다.
- 자동화는 허용된 리포트 경로만 갱신하고 다른 파일은 추가하거나 수정하지 않습니다.
